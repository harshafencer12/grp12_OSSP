STANDARD FILE DESCRIPTORS
=========================

0 -> STDIN_FILENO  -> Standard Input
1 -> STDOUT_FILENO -> Standard Output
2 -> STDERR_FILENO -> Standard Error


IMPORTANT OBSERVATIONS
======================

A file descriptor is an integer assigned by the operating
system to an opened file or I/O resource.

The lowest available file descriptor is generally assigned
when a resource is opened.

open() returns a file descriptor.

read() reads data using a file descriptor.

write() writes data using a file descriptor.

close() closes a file descriptor.

dup() creates another file descriptor referring to the same
underlying open file.

O_CREAT creates a file if it does not already exist.

O_WRONLY opens a file for writing.

O_TRUNC removes the existing contents of a file when it is
opened for writing.

CONCLUSION
==========

The programs demonstrate standard file descriptors,
