# Skill-02 Task 02 - Keyboard Input Handling

## Objective

To capture keyboard input, handle Backspace, process the Enter key, manage an input buffer, support multi-character commands, and test user interaction.

## Features

- Character-by-character keyboard input
- Enter key processing
- Backspace handling
- Input buffer management
- Multi-character command support
- Exit command
- Interactive user testing

## Source File

keyboard_input.c

## Compilation

gcc keyboard_input.c -o keyboard_input

## Execution

./keyboard_input

## Sample Interaction

Shellforge> hello
Command entered: hello

Shellforge> testing
Command entered: testing

Shellforge> exit
Exiting Shellforge...

## Result

Keyboard input handling was successfully implemented and tested.
