SKILL-03 TASK-01: COMMAND HISTORY
=================================

Compilation:
gcc -Wall -Wextra command_history.c -o command_history

Execution:
./command_history

Sample Output:

Simple Command History
Type commands. Use Up/Down arrows to navigate.
Press Ctrl+D or type exit to quit.

shell> hello
Command stored: hello

shell> linux
Command stored: linux

shell> operating systems
Command stored: operating systems


HISTORY TEST
============

After entering the commands:

hello
linux
operating systems

Pressing the UP arrow recalls:

operating systems

Pressing UP again recalls:

linux

Pressing UP again recalls:

hello

Pressing DOWN moves forward through the command history.

The program uses escape sequences generated by the terminal
to identify UP and DOWN arrow keys.

UP arrow escape sequence:
ESC [ A

DOWN arrow escape sequence:
ESC [ B

Backspace is handled by removing the last character from
the input buffer and moving the cursor back.

The input buffer is updated whenever a character is entered,
deleted, or a history command is recalled.
