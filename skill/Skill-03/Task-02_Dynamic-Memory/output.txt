OBSERVATION
===========

The program dynamically allocates memory using malloc().

realloc() is used to resize the dynamic array when the
allocated capacity becomes full.

The array size is increased when more elements are required.

A linked list is created using dynamically allocated nodes.

Each node is released using free() after use.

Valgrind is used to verify that dynamically allocated memory
has been released correctly.
